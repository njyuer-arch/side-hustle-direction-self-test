# 副业方向自测｜V3.2 内测

想多挣点钱，却不知道做什么？心里有个想法，但拿不准？或者正在做的事不顺，想换个办法？这个自测会边听边问，帮你看清下一步先考虑什么、钱可能从哪来、哪里容易白忙。

**不用准备答案。** 想到什么说什么，答不上就说不知道。一次只问一件事；已经说过的不反复问。以前做过的事会问清为什么停，不会因为过去赚过钱就劝你重新做。
