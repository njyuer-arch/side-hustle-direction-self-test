# 副业方向自测｜用户版 V0.2（内测）

给考虑副业、第二收入、轻创业，或已经有想法、正在尝试的人使用。AI 会一问一答，先了解你的经历和条件，再看谁真的有问题、现在怎么解决、可能怎样付钱。已有方向会先帮你核对这条路；还没有方向，会从真实经历提出可调查的候选。最后给你一份可以继续修改的初步报告。

这套判断结合本项目自己的经营原则，以及对姜胡说、胡说老王公开内容的学习整理；不是他们的官方测试或合作产品。建议依据你的回答和现实证据，不保证收入或替你做决定。

## 使用方法

**豆包：**切到“工作模式”，启用 GitHub 连接器，再发送下面这句话。此前的试用反馈显示普通对话可能只把链接当网页打开，未实际调用连接器；以当前界面和实际读取结果为准。

> 请用 GitHub 连接器读取公开仓库 `njyuer-arch/side-hustle-direction-self-test` 的 `main` 分支，完整读取 `START_HERE.md`、`SKILL.md` 和 `FEEDBACK_POLICY.md`。按规则一次问我一个问题，带我完成副业方向自测。如果不能读取，请直接说明，不要假装已读。

[打开公开仓库](https://github.com/njyuer-arch/side-hustle-direction-self-test)。

其他 AI 或智能体如果有 GitHub 连接器，也可用同一句话；接入方式由该平台判断。若连接器无法读取，打开 [SKILL.md](https://github.com/njyuer-arch/side-hustle-direction-self-test/blob/main/SKILL.md) 和 [FEEDBACK_POLICY.md](https://github.com/njyuer-arch/side-hustle-direction-self-test/blob/main/FEEDBACK_POLICY.md)，把两个文件上传到新对话，让 AI 完整读取后开始。上传不了 `.md` 时可复制全文。

开头会预告大约十来问，复杂情况可能多问；不知道的可跳过。提问以自由回答为主，不要求选字母。每问之后会给出到初步报告的预计剩余问数。

**想到其他情况，可以随时补充，不用等我问到。**

## 结果和反馈

报告会说：已有方向先继续、收窄还是调整；没有方向先调查什么；哪些个人经历能用；谁可能付钱、为什么；市场上已有怎样的做法；先验证什么；是否有能复用同一份投入的相邻机会。会把已发生的事实、推测和待验证之处区分开，不拆每日任务。

出初稿前，AI 会请你补充遗漏或纠正事实，并问一次是否愿意将结果摘要与后续评价匿名提交。**同意、不同意或跳过都能看报告。** 看完还可以指出说准或没说准的地方，继续补充和提问。当前没有安全的自动提交入口，因此同意也不会发生自动提交；AI 必须如实告知。详见 [反馈规则](https://github.com/njyuer-arch/side-hustle-direction-self-test/blob/main/FEEDBACK_POLICY.md)。
