# 副业方向自测｜V0.4 内测

一问一答，结合经历、已有想法、现实条件和真实客户问题，分析值得先调查或验证的挣钱方向。免费初稿可继续补充和修改，不保证挣钱。

## 最简单的用法

豆包先切到**工作模式**并启用 GitHub 连接器；ChatGPT 或其他能读 GitHub 文件的 AI 可在新对话使用。复制这一句话：

> 请用 GitHub 连接器完整读取这一个文件，告诉我读到的版本，然后按文件规则持续一问一答；我每回答一次，你就提示还需约几问并主动问下一题，直到给初稿。读不到就直接说，不要自行编题：https://github.com/njyuer-arch/side-hustle-direction-self-test/blob/2e4e7ae34d887d10c70ce179db8a2d71a8f159ac/SKILL.md

这是 V0.4 的固定版本链接，用来避免从仓库首页读到旧缓存或把多份文件混用。[仓库主页](https://github.com/njyuer-arch/side-hustle-direction-self-test)保留最新文件和版本记录。如果 AI 读不到上述文件，打开链接下载 `SKILL.md` 上传到新对话，说“请完整读取文件，按规则持续逐问自测”；不接受 `.md` 时可保存为 `.txt` 或粘贴全文。

AI 的第一条回复应报 **V0.4**、简短预告、显示预计剩余问数，再问第一题；之后每次回答都应主动追问。若没有继续响应，先检查平台是否仍在生成或是否提示任务结束，必要时在同一对话说“请承接我上一条回答继续下一题”。如仍不回应，换新对话上传文件；提示词不能修复平台不继续接收消息的问题。

**想到其他情况，可以随时补充，不用等我问到。**

报告前可补充遗漏，报告后可纠正并继续提问。当前没有安全的匿名自动提交入口，不会自动上传结果；未来真正提交仍须重新取得当次授权。本工具吸收项目经营原则与对姜胡说、胡说老王公开内容的学习整理，不是他们的官方产品。
