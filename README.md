帮助考虑副业、创业、转型或增加收入的人，不只评估已有想法，也主动从工作经历、能力、兴趣、关系资源和当前项目产生的内容/案例/方法里发现可能的挣钱方向；比较哪些可能更快见钱、哪些能以较低新增成本积累。结果是可修订的机会判断，不是落地执行方案。

## 怎么用

豆包先进入**工作模式**，启用 GitHub 连接器。ChatGPT、WorkBuddy 或其他能读 GitHub 文件的 AI 用同一句话：
