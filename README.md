# 个人商业机会判断｜V4.1 真人测试版

这个工具通过聊天，帮你判断一个副业、创业想法或现有生意里的赚钱机会。它会先弄清你这次想解决什么，再看客户是否真的想买、为什么选你、怎样接触和服务客户、最终能否留下钱，同时考虑你愿不愿长期这样做。不需要先想好要问什么。

## 豆包、GPT、WorkBuddy 用法

新开对话，选可以读取公开 GitHub 网页的模式，复制以下文字：

> 请读取 https://github.com/njyuer-arch/side-hustle-direction-self-test/blob/main/SKILL.md 的全文，核对 V4.1 和识别句 SHDST-20261011-V410。读不到全文或核对不上就告诉我并停止，不要自己编题。核对成功后按文件规则和我聊我的副业、创业或生意选择。先听我这次想解决什么，必要时只问一个容易回答的问题；请主动帮我分析客户现在怎样解决、为什么可能选我，以及还有什么别的走法。我不清楚的事请和我一起推演，别让我独自回答一份问卷。
