# 副业方向自测｜V4.0 极简测试版

这是一个用聊天帮你想清副业或创业选择的工具。你不用先想好问题；有想法可以聊想法，不想再做以前的事也可以直说。它会帮你看清自己真正想解决什么、哪些选择值得考虑、哪里还需要找真实证据。

## 豆包、GPT、WorkBuddy 的用法

新开对话，在能读取 GitHub 公开文件的模式下复制：

> 请读取 https://github.com/njyuer-arch/side-hustle-direction-self-test/blob/main/SKILL.md 的全文，核对 V4.0 和识别句 SHDST-20261011-V400。读不到全文或核对不上就告诉我并停止，不要自己编题。核对成功后按文件规则和我聊副业或创业选择。先听我想解决什么，直接回答我的问题；需要问时一次只问一件容易回答的事。不要因为我提到一个项目或旧经历，就认定我要做它。
