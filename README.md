# 副业方向自测｜V1.0 内测

帮助考虑副业、第二收入、转型或创业的人，看清已有方向的适配度、风险和遗漏，同时从个人经历、能力、兴趣、关系资源和项目副产品中发现没想到的挣钱机会。

## 怎么用

豆包先进入**工作模式**并使用 GitHub 连接器。其他能读取 GitHub 的 AI 使用同一句话：

> 请通过 GitHub 连接器读取公开仓库 njyuer-arch/side-hustle-direction-self-test 的 main 分支 SKILL.md 全文，核对标题 V1.0 和识别句 SHDST-20261009-V100。读不到或不一致就如实说明并停止。核对一致后按规则持续一问一答。问题要具体好懂，按入口调整追问；除了评估我提出的方向，还要发现我可能没想到的挣钱机会，并查清我这个方向的主要风险、遗漏前提和时间安排。每次回答后继续一个问题，按入口调整顺序；显示已完成主线数、待完成主线数和当前题号，追问不按次数改变主线计数；完成主线、必要追问、机会扫描和风险核查后再出报告，除非我明确要求提前看。报告要说清新机会怎么变现、边际方向复用什么、风险依据是什么，并区分事实和推演。不要询问匿名反馈。读不到请直说，不要自行编题。

[打开 GitHub 仓库](https://github.com/njyuer-arch/side-hustle-direction-self-test) · [目标与要求总纲](GOAL_AND_REQUIREMENTS.md)

**想到其他情况，可以随时补充，不用等我问到。**

想不起某题可以跳过，也可以随时暂停或先看标明未知的阶段性初稿。

本工具服务三类人：没想好方向、有想法拿不准、已经在做或刚停下。30个编号主线题按入口调整顺序，并随回答切换重点；无具体客户时从经历和接触过的人切入，后续出现候选再补查交易事实；报告既要让用户看到新可能，也要帮助其看清当前方向的风险。现有核查属于规则桌面走查，尚不代表豆包或 GPT 真实平台实测。当前不自动收集或提交匿名反馈。
