# 副业方向自测｜用户版 V0.1

这是一个正在内测的免费方向自测工具，适合正在考虑副业、第二收入、转型或创业的人。

它会根据你的真实经历、目标、时间、资金和现有条件，帮你分析：

- 现在优先试什么；
- 为什么值得先试；
- 谁可能付钱、钱从哪里来；
- 主要风险是什么；
- 第一轮先验证什么。

它不是天赋测试或职业算命，不会保证赚钱，也不会替你做人生决定。

## 最简单的使用方法

把这个仓库地址发给支持读取 GitHub 的 AI，然后说：

> 请先读取仓库里的 START_HERE.md 和 SKILL.md，再按里面的规则帮我完成副业方向自测。

如果你的 AI 不能直接读取 GitHub，就下载 `SKILL.md` 后上传，或者把其中的内容复制到新对话里。

AI 应先简短说明：

> 接下来我会一次问你一个问题，通常需要回答 8—10 个。主要了解你想解决的问题、希望多久见到收入、能投入的时间和资金、过去做成的事情、现有资源和已有想法。
>
> 不适合你的问题，暂时想不起来或确实不知道，都可以直接说“跳过”或“不知道”。
>
> **想到其他情况，可以随时补充，不用等我问到。**

然后给出第一道选择题：

> 先选一个最符合你现在情况的：
>
> A. 完全没有方向，不知道可以做什么  
> B. 有一两个想法，但不知道该选哪个，或者是否适合  
> C. 已经选了一个方向，但不知道第一步该怎么做  
> D. 已经开始做了，但遇到了具体问题

## 关于匿名反馈

自测完成后，AI只会问一次：

> 愿意把本次自测结果和评价匿名提交，帮后来的人把工具做得更实用吗？

只有你明确同意才允许提交；拒绝、不回答或撤回都不提交。当前版本尚未接通满足“只能提交、不能读取他人记录”的安全入口，所以 AI 不得声称已经自动提交。

详细规则见 `FEEDBACK_POLICY.md`。

## 文件说明

- `START_HERE.md`：给不同 AI 的读取入口
- `SKILL.md`：完整自测规则
- `FEEDBACK_POLICY.md`：匿名反馈与权限边界
- `VERSION.md`：版本与变更记录
