# 副业方向自测｜V2.0 内测

用一次短访谈，帮你从真实经历里找值得验证的挣钱机会，也检查现有想法最要紧的风险。问题按回答走，不要求答完固定问卷；答不上来可以说“不知道”或“跳过”。
