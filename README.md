## 最简单的用法

豆包先切到**工作模式**并启用 GitHub 连接器；ChatGPT 或其他能读 GitHub 文件的 AI 可在新对话使用。复制这一句话：

> 请用 GitHub 连接器读取公开仓库 `njyuer-arch/side-hustle-direction-self-test` 的 `main` 分支 `SKILL.md` 文件，核对文件里的版本识别句并告诉我版本。按文件规则持续一问一答；我每回答一次，你就显示预计还剩几问，主动问下一题，直到给初稿。读不到请直说，不要自行编题。

[仓库入口](https://github.com/njyuer-arch/side-hustle-direction-self-test)。对连接器明确说仓库名、`main` 分支和 `SKILL.md` 路径；不要依赖它猜仓库首页或解析带提交编号的文件链接。V0.4 自测只需读取这一份完整文件。连接器返回错误时如实说明，不能假装读到。

AI 的第一条回复应报 **V0.4**、简短预告、显示预计剩余问数，再问第一题；之后每次回答都应主动追问。若没有继续响应，先检查平台是否仍在生成或提示任务结束；连接器读取失败和对话中途不响应是两个不同问题，分别记录。
