# 副业方向自测｜用户版 V0.1

这是一个正在内测的免费工具，适合想做副业、增加收入、轻创业，以及已经有想法或正在尝试的人。

它通过一问一答了解你的想法、经历和现实条件，帮你看清：现有想法是否值得继续；没有想法时可以先试什么；你可能忽略了哪些可用经验；谁可能付钱、钱怎样来；现实风险和第一轮验证目标。它不保证赚钱，也不替你做决定。

## 使用方法

把本仓库地址发给能读取 GitHub 的 AI，告诉它：

> 请先完整读取这个仓库的 START_HERE.md 和 SKILL.md，再按规则帮我做副业方向自测。

当前主推豆包、GPT / ChatGPT、WorkBuddy；各平台读取 GitHub 的能力和方式仍需分别实测。读不了 GitHub 时，下载 `SKILL.md` 上传给 AI，或把全文复制到新对话中。

AI 会先简短说明：大约十来问，内容涉及想法、经历、时间和钱，具体问题会随回答变化；不知道的可以跳过。它会单独提示：

> **想到其他情况，可以随时补充，不用等我问到。**

接着只问一个开放问题，不要求你选字母；你可以自由讲自己的想法、经历和进度。AI 应接着你的回答继续问，不会让所有人照同一张问卷回答。

## 你会拿到什么

一份简短的方向判断：建议先验证什么、依据是什么、可能的付款人和收入路径、目前的限制与风险、第一轮要验证的事。自己认为的优势与 AI 从真实经历发现的可能能力会分开说；没有证据的部分会写“待验证”。不会生成详细每日任务表或保证收入。

## 当前状态与反馈

- 版本：V0.1，首轮验证，提问与报告仍会按真实样本修订。
- 自动匿名反馈回写：尚未开启。

报告后，AI 最多询问两项结果评价，然后只问一次：

> 愿意把本次自测结果和评价匿名提交，帮后来的人把工具做得更实用吗？

只有明确同意才可提交；拒绝、不回答或撤回都不提交。当前没有符合“只能提交、不能读取他人记录”的安全入口，因此 AI 不能声称已经自动提交。详见 `FEEDBACK_POLICY.md`。

## 文件

- `FEEDBACK_POLICY.md`：匿名反馈和权限边界
- `VERSION.md`：版本记录
