# 副业方向自测｜V0.9 内测

适合还没想好方向、有想法拿不准、已经在做但想检查风险的人。AI 会逐题了解经历、现实条件和谁可能付钱，再核查候选方向、现有解决方式与个人能否进入交易；最后给主方向、可复用的边际方向和第一步验证。结果是可修订初稿，不保证挣钱。

## 怎么用

豆包先进入**工作模式**，启用 GitHub 连接器。ChatGPT、WorkBuddy 或其他能读 GitHub 文件的 AI 用同一句话：

> 请用 GitHub 连接器读取公开仓库 njyuer-arch/side-hustle-direction-self-test 的 main 分支 SKILL.md 全文。先核对标题为 V0.9、识别句为 SHDST-20261008-V09；不一致就告诉我实际读到的版本并停止，不要开始测试。核对一致后按文件规则持续一问一答。每次我回答后主动继续，显示主线题号或追问编号。读不到请直说，不要自行编题。

[仓库入口](https://github.com/njyuer-arch/side-hustle-direction-self-test)。现行规则只需读取 SKILL.md，按仓库名、main 分支和文件路径找；不要从仓库主页猜，也不要靠旧对话记忆。

**想到其他情况，可以随时补充，不用等我问到。**

V0.9整合公开仓库借鉴的市场核查流程与匿名反馈功能，约30个主线问题，必要时追加追问；没有固定总问数。报告后可继续补充并修订。所有内容修订完成后，AI会先展示去身份摘要、重新征求是否提交：ChatGPT 等已连接站点 MCP 工具的平台可单向提交；其他平台可用[匿名反馈表单](https://side-hustle-feedback.lunarbook1.chatgpt.site)。拒绝、跳过或没有明确同意都不提交。测试者不能读取他人反馈。工具吸收项目经营原则与对姜胡说、胡说老王公开内容的学习整理，不是两位创作者的官方产品。
