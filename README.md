# 副业方向自测｜用户版 V0.3（内测）

用一问一答了解你做过什么、现在想做什么、谁可能真的需要，以及先怎么小规模验证。已有想法会先分析它；还没有想法，会从经历中寻找候选。报告会说清依据和不确定的地方，不能保证挣钱。

本工具结合项目自己的经营原则及对姜胡说、胡说老王公开内容的学习整理，不是他们的官方产品。

## 开始使用

推荐豆包**工作模式**或 ChatGPT。把下面这段话发给 AI：

> 请从 GitHub 重新读取这个公开仓库 `main` 分支的 `START_HERE.md`、`SKILL.md`、`FEEDBACK_POLICY.md`，核对 `SKILL.md` 中的当前版本识别句，先告诉我版本，再一次只问一个问题，带我完成副业方向自测。不要沿用旧对话里的文件。若读不到，请直接告诉我，不要自行编题。
>
> https://github.com/njyuer-arch/side-hustle-direction-self-test

豆包需切到“工作模式”并启用 GitHub 连接器。其他 AI 如无法直接读取，打开仓库下载 `SKILL.md` 和 `FEEDBACK_POLICY.md`，上传到新对话后说“请完整读取我上传的文件，再按规则逐问自测”。若不识别 `.md`，可保存为 `.txt` 或粘贴全文。使用旧聊天继续时，先让 AI 重新读取 V0.3，旧回答不用重答。

AI 开始应说“已读取副业自测 V0.3”，每次问题前都要出现预计剩余问数；没有做到，可提醒它重新读规则。问题以自由回答为主，不知道的可跳过。

**想到其他情况，可以随时补充，不用等我问到。**

## 结果与反馈

初稿前有开放补充机会，报告后也可以纠正事实、继续提问。它会核对你的原有想法、能力能否接入现有事情、是否值得单独卖成服务，不能只因你会某项工作就断言有人付钱。目前安全的匿名自动提交入口尚未接通，本次不会自动上传任何结果；是否愿意参与以后反馈不影响看报告，未来真正提交须重新征求授权。详见 [反馈规则](https://github.com/njyuer-arch/side-hustle-direction-self-test/blob/main/FEEDBACK_POLICY.md)。
